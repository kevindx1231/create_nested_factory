# Minecraft 1.20.1 logistics compatibility

Java sources and resources in this directory are compiled into the root mod JAR by the main source set; this is not a separate mod.

Targets: Mekanism 10.4.16 and Pipez for Minecraft 1.20.1. Versions and dependencies are configured in the root `gradle.properties`. See the root README and v1.5.23 release notes for supported behavior and validation scope.
