# 嵌套扩展接口手动测试矩阵

## 绑定与显示

1. 对嵌套工厂六个不同面分别放置接口，确认每个接口只绑定被点击的工厂面。
2. 在空地放置接口，确认护目镜显示“工厂：未绑定”“当前模式：—”“接口状态：未绑定”。
3. 在未绑定接口记录方向旁放置另一座工厂，确认接口不会自动绑定。
4. 移走原工厂后再恢复同一工厂身份与邻接关系，确认接口重新启用；换成另一座工厂则保持未绑定。
5. 已绑定接口应显示工厂名称、宿主面的当前模式以及“已启用”；通入红石后只把状态改为“已禁用”。

## 模式与红石

1. 普通扳手右键任意外露面，确认循环顺序为 `none → input → output → none`，工厂宿主面同步改变。
2. 红石禁用时继续用普通扳手修改模式，确认配置仍可改变；潜行扳手应回收接口且掉落物不保存绑定。
3. 接口绑定后，直接查询被接管的工厂原面，确认物品、流体、包裹、化学品、热量和应力都不能绕过接口。
4. 红石开关前先让管道缓存接口能力；开关后使用同一管道继续传输，确认已缓存的处理器也拒绝操作。

## 五面物流

1. 对五个外露面逐面验证物品输入、物品输出、流体输入和流体输出；贴附面不得暴露能力。
2. 验证 Create 包裹只能整包接受或整包拒绝，不产生部分解包。
3. 使用机械泵从任意外露面驱动 Create 流体管网，确认压力能跨接口映射到 Pocket 端口；切换模式、红石或拆除接口后不保留旧压力。
4. 安装物流兼容模块后，从五面分别验证 Mekanism 化学品；热量在 input/output 均保持双向，在 none、红石禁用或未绑定时断开。
5. 同一逻辑端口由多个工厂面及多个扩展接口共享时，确认输入需求与输出托管不会复制。

## 应力与移动

1. 从五个外露面分别接入有效传动杆，确认接口把外部应力传给内部嵌套应力端口，且端口模式不影响应力。
2. 同时接入多个不同动力网络，确认只选择剩余容量最大的单一网络；相同网络从多个面接入时只计算一次。
3. 通入红石，确认外部应力预留立即释放且内部端口停机；解除红石后可恢复。
4. 在 Pocket 子工厂、不同嵌套层级以及 Simulated/Sable 物理载体上重复绑定测试；结构整体移动或旋转后，只要身份和邻接仍成立就应继续工作。
