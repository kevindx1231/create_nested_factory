# v1.5.22 — Minecraft 1.21.1

发布日期 / Release date: 2026-10-18

## 更新日志

### 黑盒学习与来源认证

- 树场按树苗种类、农场按作物类型分别认证。观察到生长活动后，该组加入学习等待；生长本身不代替完整生产循环及对应边界输出。
- 闲置树苗、作物和没有生产活动的来源不再阻塞已经完成的独立加工路线，也不获得黑盒生产权限。没有独立加工路线的自然来源仍可等待生长。
- 默认学习绝对期限由 6000 tick 调整为 3600 tick（20 TPS 时为 3 分钟），从切换请求开始计算。生长不重置期限；参与来源到期未认证时整次学习退回常加载，不发布部分路线。现有配置文件中的自定义值保持有效。
- 发布前依据完整观察与房间物料账本重新编译，防止过早候选计划掩盖后续耗损，或将未认证来源产物当作普通加工产物。
- 保留混合计划拆分、组合及复制时的启动资本要求，并增加闲置来源、生长未收获、晚启动来源、混合加工、期限和资本回归。

### Ponder 教程

- 新增 7 个中英文场景：工厂空间、跨边界物流、应力供给、黑盒学习、蓝图复用、多层嵌套，以及搬运与保存。
- 包含共享剖面、辊压动画、三段学习示意和 42 段双语字幕。将鼠标移到嵌套工厂物品上，按住提示按键（默认 W）即可查看。
- 教学场景采用缩略空间和压缩时间，不创建真实 Pocket 房间或提交模式切换请求。演示范围见 [Ponder 说明](https://github.com/kevindx1231/create_nested_factory/blob/mc1.21.1/docs/ponder-first-pass.md)。

### 冻结兼容性

- 修复 Observable 5.4.4 与方块实体冻结入口的 Mixin Redirect 冲突，使用 MixinExtras v2 条件包装保留第三方计时调用链。
- 非冻结区域继续正常 tick，冻结区域跳过执行，解冻后恢复；保留 Lithium 0.15.4 随机刻兼容和关键冻结入口的强制注入检查。
- 增加四种模组组合的独立 GameTest 及固定依赖校验脚本；测试代码、模板与世界预设不进入正式 JAR。

## Release notes

- Tree and crop evidence is verified per group. Observed growth joins source waiting but does not replace complete production cycles and matching boundary output. Idle sources no longer block completed independent processing or gain production rights; natural-only factories retain their growth wait.
- The default absolute learning deadline changes from 6000 to 3600 ticks (3 minutes at 20 TPS), starting at the switch request. Growth never resets it. Unverified participating sources fail the entire session back to chunk-loaded mode without publishing partial routes. Existing configured overrides remain effective.
- Publication recompiles against the complete observations and room ledger, preventing stale processing candidates and uncertified source output from bypassing accounting. Mixed plans retain startup capital when routes are split, combined, or copied.
- Adds seven bilingual Ponder tutorials covering rooms, logistics, stress, black-box learning, blueprints, nesting, and moving/preservation, with 42 captions per language. Hover over the Nested Factory item and hold the prompted key (W by default). Scenes use teaching diagrams and compressed time without changing real factories.
- Fixes the Observable 5.4.4 block-entity tick Redirect conflict using a MixinExtras v2 conditional wrapper. Normal ticks and profiling remain intact outside frozen rooms; frozen ticks are skipped and resume after thawing. Lithium 0.15.4 random-tick compatibility and required freeze injections remain enabled.
- Adds isolated integration tests for base dependencies, Lithium, Observable, and both together. Test classes, structures, and world presets are excluded from the release JAR.
