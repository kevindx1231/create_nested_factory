# v1.5.23 — Minecraft 1.21.1

发布日期 / Release date: 2026-10-26

## 更新日志

### 同层蓝图工厂与空间绑定

- 同一空间可继续放置嵌套工厂：首个工厂取得下一层空间入口，后放工厂仅支持应用蓝图，不创建内部空间。
- 入口工厂拆除后立即释放资格，旧蓝图方块不自动升级；新放工厂可以创建独立空间。
- 带绑定的旧工厂可在入口被占用时放回，仅运行应用蓝图；原空间保持冻结，取消蓝图不会开放入口，拆除后仍掉落原绑定工厂。
- 修复首个工厂护目镜错误显示“该空间已有可进入的嵌套工厂”。受限状态直接同步到客户端，不再依赖客户端查询服务端父工厂。
- 普通挖掘、潜行扳手拆卸及 GUI 销毁共用内部子工厂、玩家和房间变更保护；潜行扳手保留绑定掉落。
- 合并蓝图取消和停机分支，移除无效转发；内部工厂检查改为按区块遍历方块实体，避免逐方块扫描。
- 旧版合法位置上的无空间无效工厂迁移为受限蓝图工厂；重载不争抢入口，空间绑定不重分配。

### 绑定物品与空间保护

- 修复绑定工厂物品丢失、烧毁、爆炸销毁、自然消失或被磁铁收取时误触发原空间清理的问题。物品消失后继续保留空间、身份和绑定记录，管理员可使用 `/cnf copy <id>` 恢复绑定物品。
- 空间清理通过 GUI 销毁或 `/cnf delete <id>` 显式执行。清理完成前不回收空间槽位，已删除的旧绑定不能重新占用被回收的空间。

### 内置 Ponder 教程

- 恢复内置 Ponder 教程，共 8 个教学章节：工厂进出、物流、黑盒与搬运、多层嵌套与蓝图、普通端口、应力端口、扩展接口和工厂通道。
- 加入教学结构、中英文标题与字幕，以及“嵌套工厂组件”分类和专属分类页标题。教程随模组打包，无需额外安装 The Ponderer。
- 更新中英文 README 的当前版本、下载链接、同层放置规则、绑定保留、拆除保护及教程说明。

## Release notes

### Blueprint-only siblings and room bindings

- Additional factories can be placed in the same parent room. The first receives next-level room entry; later factories run applied blueprints without creating rooms. Terminal blueprint-only factories remain available beyond the room depth limit.
- Removing the entry holder immediately frees eligibility. Existing blueprint factories are never automatically promoted; a newly placed factory can create its own independent room.
- A bound factory can be replaced in its original parent while entry is occupied. It can run applied blueprints while its original room stays frozen. Blueprint cancellation does not reopen entry, and removal preserves its binding. Replacing it after entry becomes vacant restores its original room.
- Fixes the occupied-entry goggle warning incorrectly appearing on the first factory by syncing restriction state directly to the client.
- Migrates legacy roomless invalid factories in legal positions to blueprint-only factories. Reloading neither claims an entry nor reallocates an existing binding.

### Removal safeguards and item-loss fixes

- Normal breaking, sneak-wrench removal, and GUI destruction share checks for internal factories, players, and active room tasks. Roomless blueprint children also protect their parent from removal, and wrench removal preserves bound drops.
- Fixes unintended room cleanup when a bound factory item is lost, burned, exploded, despawned, or collected by a magnet. The room, identity, and binding survive; operators can recover a lost bound item with `/cnf copy <id>`.
- Room cleanup requires explicit GUI destruction or `/cnf delete <id>`. Slots are released only after cleanup, and retired bindings cannot reclaim a reused slot.
- Consolidates blueprint cancellation and shutdown paths, removes redundant forwarding, and checks internal factories through per-chunk block entities rather than scanning every block.

### Built-in Ponder tutorials

- Restores 8 Ponder chapters covering entry and return, logistics, black-box mode and relocation, nesting and blueprints, ports, stress ports, extension interfaces, and factory passages.
- Bundles teaching structures, Chinese and English captions, and a dedicated Nested Factory Components category and heading. The Ponderer is not required at runtime.
- Updates both README languages for the release version, download links, placement rules, binding retention, removal safeguards, and tutorials.

## 手动验收顺序

1. 放置 A，再放 B/C：A 可进入且无占位提示，B/C 只支持蓝图。
2. 给 B 应用物品及流体生产蓝图，提供原计划所需资源和动力，检查输出。
3. 在 A 内放任意嵌套工厂：普通挖掘、潜行扳手拆卸及 GUI 销毁 A 均应被拒绝；移除内部工厂后可搬运 A。
4. 拆 A 后放 D：D 创建新空间，B/C 不升级。放回 A：A 不可进入，旧空间不运行，但应用蓝图后可生产。
5. 取消 A 的蓝图、重启服务器：A 仍受限。再次拆 A，应掉落保留原绑定的工厂。
6. 拆 D，在空缺时重新放 A：进入原空间；使用 D 的绑定物品也应保留 D 原空间。两者不得串房或重复分配。
7. 检查绑定物品烧毁、消失与磁铁收取后空间未被清理；使用管理员复制品恢复原空间。
8. 在中文和英文客户端检查 8 个 Ponder 章节、字幕、结构及分类页标题。
