# 使用零缓存边界与单批次生产状态传输资源

工厂边界不再提供通用物品库存或流体储罐：真实运行与学习通过标准 NeoForge 能力执行由玩家物流调用驱动的同步直通，黑盒与蓝图只保留一个不可访问的物品/流体统一生产批次状态。相同 ID 的内部端口组成共享路由的端口组，四种传输方向使用独立持久化轮询游标；端口严格执行 INPUT/OUTPUT 方向，流体压力镜像到组内所有端口，但实际数量由共享协调器守恒。该取舍移除了固定槽位和 1000 mB 中转罐的吞吐上限，同时接受异步物流组合被拒绝、物品批次失效时可物化并绕过输出物流、流体批次失效时直接销毁。
