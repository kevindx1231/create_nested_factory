# 将内部应力供给纳入黑盒计划

真实空间学习同时记录外部应力需求、内部发电、总消耗及其峰值。内部发电先抵扣真实工厂的应力需求，黑盒与蓝图只向外部网络预留剩余需求；外部需求为零的再生路线只有在计划保存了正的内部发电证明时才有效。

内部供能合同由 `FactoryPlan` 持久化并参与计划指纹、验证、复制、蓝图和超频。模拟模式不加载真实空间，也不重新扫描内部动力；它只重放已经验证的计划值。超频只增加生产负载，内部发电保持学习时的固定能力，外部应力需求按“超频后负载减去可用内部供给”重新计算。计划格式硬切换为 7，蓝图标记同步切换到 v7，旧计划和旧蓝图不迁移。
