# 使用端口组物品交接缓冲兼容主动物流

本提案接受后将取代 ADR-0001 的全资源零缓存边界。每个端口 ID 只有一份由全部同 ID `nested_port` 共享的九槽物品交接缓冲；增加内部端口不会增加容量或复制资源。缓冲使用标准九槽物品堆叠规则并保留完整 Data Components，不向玩家开放 GUI。对应端口 ID 没有有效内部端口时，外部 INPUT 面拒绝输入。

能力严格服从端口方向：INPUT 面允许外部插入、内部提取；OUTPUT 面允许内部插入、外部提取；NONE 和无方向查询不暴露物品能力。普通对侧端点能够立即接收时优先同步直通，未交付的剩余部分才进入缓冲。物品成功写入缓冲时即完成该方向的边界传输和学习记账，随后被另一侧物流提取时不得重复记录。该方案允许 Create 传送带漏斗和独立安山/黄铜漏斗通过普通 `IItemHandler` 在正常 tick 中执行原生行为，不需要 Mixin、反射或复制 Create 私有流程。

缓冲非空时的顺序语义、配置和模式变更、区块与存档生命周期、工厂销毁以及损坏数据恢复仍待后续决策，因此本 ADR 暂为 proposed。
