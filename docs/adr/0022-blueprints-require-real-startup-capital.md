# 蓝图只复制会被消耗或可提取的启动资本合同

黑盒计划声明树苗、催化剂和受托工具等首次运行所需的启动资本，蓝图复制该合同但不复制任何真实资源。新工厂只有从外部一次性提交完整资本后才能启动相关路线；资本保持不可访问托管，退出黑盒时返回真实空间，并随便携工厂和航空学移动迁移。

内建圆石与玄武岩来源的水、岩浆、蓝冰和灵魂土只构成已认证来源结构，不参与配方消耗，也不能从模拟工厂中提取，因此蓝图直接复用该来源证明而不要求再次提交这些方块或流体。该豁免只适用于内建圆石和玄武岩证明；树苗、工具、燃料、普通催化剂及第三方来源声明的资本不自动豁免。已有有效计划和蓝图在读取并校验原指纹后移除这些旧结构资本。
