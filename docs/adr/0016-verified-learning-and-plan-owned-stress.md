# 使用受控运行验证加工路线并由计划拥有应力合同

普通加工路线不再由固定时间内的端口吞吐总量直接生成。学习依次经过预热、基线、受控运行和独立验证，只有边界投入产出、工具损耗、内部资本与可观察在制状态完成对账后才发布路线；无法形成完整证据的结构保持真实运行。

路线阶段负载、峰值应力、参考转速和总 SU·tick 由黑盒计划唯一保存并纳入计划指纹，黑盒运行和蓝图均从计划读取。动力档案只描述真实空间的当前动力状态，不能作为第二份黑盒运行权威。

学习不使用可降为负数的总倒计时。每个受控实验使用无有效事件超时，只有真实输入、生产、状态复位或来源周期事件能够刷新；超时使工厂返回真实模式并保留休眠计划，不能用不完整数据强制编译。

学习状态不跨服务器重启恢复。重载时放弃未完成实验、合并传输代次并回到真实模式，已经真实消耗或交付的资源保持现状，休眠计划不受影响。
