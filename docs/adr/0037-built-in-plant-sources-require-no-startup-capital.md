# 内建植物来源蓝图不再要求种植物启动资本

经过当前树场或农场来源适配器验证的无物料输入计划，复制为蓝图后不再要求重新提交树苗、种子或其他种植物。来源证明、产出额度、工具耐久和生产应力合同仍然完整保留；新工厂应用蓝图后，只要满足计划应力、受托工具和输出交付条件即可运行。

通用启动资本合同继续保留给第三方来源适配器声明的真实催化剂、燃料或其他不可凭来源证明复制的物品。内建圆石、玄武岩、树场和农场均不声明启动资本。普通加工路线的物品与流体投入，以及学习到的耐久工具成本，不受本决定影响。

树场来源证明升级到版本 7，农场来源证明升级到版本 2。旧证明、旧黑盒计划和旧蓝图不迁移，必须重新学习并重新保存蓝图，以免同一证明版本同时表达两种不同资本规则。
