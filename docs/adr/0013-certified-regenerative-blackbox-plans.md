# 以来源认证的完整周期支持再生黑盒计划

黑盒计划以完整周期的整数资源向量、完整物品/流体身份、工具耐久成本和去重后的峰值外部应力运行。没有外部物料输入的计划只有在刷石、玄武岩、树木或已注册适配器观察到完整再生周期后才有效。

混合计划拆为加工路线和已认证再生路线，两条路线共享整厂应力预留，但分别持有投入、进度、工具和输出托管。只有按再生事件计数或由适配器提供事件级归因的产物才能在混合样本中独立运行；来源不明的产物保留在物料耦合路线。真实房间及所有已加载后代在模拟期间释放强加载并持久化祖先冻结标记。

计划、运行时和蓝图使用 v4 硬切换。旧黑盒、旧运行时和旧蓝图不迁移、不读取，因为它们缺少来源、周期和资源归属证据。
