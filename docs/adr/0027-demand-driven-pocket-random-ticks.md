# 按需执行工厂空间随机刻

工厂区块的持久加载与无人时的随机刻使用两份独立票据。普通常加载继续维持机械、方块实体和传输网络；只有真实空间处于常加载、黑盒准备或黑盒学习阶段，房间内没有玩家，并且房间内部至少存在一个声明需要随机刻的方块状态时，才附加强制 tick 票据。

玩家进出时立即刷新随机刻租约，无人状态下每 100 tick 复核一次。扫描先用区块节的随机刻计数跳过无关节，再检查房间边界内的具体方块状态。植物成熟、树木被收割或随机刻结构消失后会撤销票据；机器重新种植后会在下一次复核时恢复。共享区块分别计算加载所有者与随机刻所有者，最后一个随机刻所有者释放前不会停止其他工厂需要的随机刻。

黑盒激活、蓝图和祖先冻结仍释放真实空间，不参与随机刻。黑盒学习必须保留按需随机刻，因为玩家在学习期间不能进入房间，树场需要在无人状态下完成生长样本。
