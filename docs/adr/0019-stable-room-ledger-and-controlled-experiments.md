# 以稳定房间账本支持受控路线实验

精确学习使用稳定参与者身份记录内部资本、工具和在制状态：普通资源以方块位置、能力类型和逻辑槽位识别，传送带、掉落实体、运动结构及机器在制品由类型化观察适配器提供。能力包装器对象身份和库存总数不再作为防刷依据，无法稳定观察的结构不发布黑盒计划。

混合工厂依次执行无输入、单输入、完整输入、缺一输入和经选择的并发受控运行。只有能够重复验证的依赖才拆成独立路线，无法复位或实验数量超过配置上限时保持真实运行，从而避免用两段产量差推断随机来源或重复计算共享设备能力。

封口准备会隔离旧输入托管。无输入基线关闭新输入，后续实验只开放指定逻辑端口、完整资源身份和计量额度；历史输出仍可被外部物流提取，但不进入当前学习代次。玩家从封口准备开始不得进入空间，未获适配器授权的结构变化立即使本次学习失败。

房间账本中的有限库存耗损默认仍是加工成本。已认证来源能够产出的同类旧库存属于历史输出积压：只有该资源在当前样本确实穿过输出边界、同时没有穿过输入边界时，才不再合并为配方输入；真实经过输入边界的同类资源以及只在内部被继续加工的资源仍按成本记账。带来源证明却没有归因出任何再生产物的候选计划直接作废，不能退化成“输入来源产物、再输出同一产物”的加工路线。内建圆石、玄武岩和树场证明在修改该规则时同步升级版本，使旧计划重新学习。

房间账本与端口边界必须使用同一资源身份。Create 包装箱在两处都展开为箱内完整物品身份，空箱仅是运输载体；因此箱子在打包机中生成或离开不会成为配方成本，而预置在箱内的有限资源仍会被对账。

最短采样时间只决定普通加工路线何时可以编译。检测到圆石、玄武岩或扩展再生来源后，受控运行和验证必须等待来源达到其完整循环数；不能因为经过最短采样时间而把尚未就绪的来源提交给编译器。无新事件达到停滞超时后再失败，慢速来源不会在固定采样边界被提前拒绝。
