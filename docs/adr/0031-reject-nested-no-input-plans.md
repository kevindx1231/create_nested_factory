# 禁止把嵌套无输入配方合并到父黑盒

父工厂学习时不再吸收位于其空间内的黑盒或蓝图无输入路线。只要任意层级的已加载子工厂处于模拟模式，并包含没有物品、流体输入的再生路线，父工厂就在准备阶段之前拒绝开始学习，并记录子工厂 ID 和模式。

无输入生产与后续加工必须拆成两个独立工厂。例如，第一个黑盒只根据应力生产圆石，第二个普通黑盒学习“输入圆石、输出沙砾”，两者通过外部物流连接。圆石跨第二个工厂的真实输入边界后，沿用普通配方的输入计账、防刷、超频和传输规则。

父工厂不再监听子工厂的批次生产和提取事件，不继承子计划证明，也不跳过子工厂缓存。原有物理圆石、玄武岩、树场以及扩展适配器的无输入学习不受影响；普通输入输出子工厂仍可按现有嵌套和冻结规则工作。

该决定取代原“认证嵌套计划组合”方案。已有包含 `create_nested_factory:nested_plan@1/` 证明的旧计划不会被当前证明验证器接受，需要按两个独立工厂重新学习。
