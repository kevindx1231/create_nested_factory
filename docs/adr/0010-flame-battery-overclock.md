# 使用烈焰电池提供离散超频

嵌套工厂在黑盒运行和蓝图模式中以固定基础生产周期处理一份确定配方。烈焰电池为玩家提供 0.5 倍、2 倍至 5 倍的离散超频档位，同时必须保持已提交批次、端口能力、应力预留和蓝图语义一致。

烈焰电池是最大堆叠数为 64 的普通物品，但工厂拥有四个专用槽位，每槽只接受一块。槽位按顺序解锁：第 N 槽要求之前所有槽位都装有电池；移除时必须从最后一个已占用槽位开始。工厂破坏时掉落已安装的电池。应用、取消或复制蓝图不会移动、复制或清除目标工厂的电池和超频选择。

无电池时滑块锁定于 1 倍，灰色滑块位于 (116,87)。安装第一块电池后自动选择 2 倍，滑块变为白色，并可选择 0.5 倍或 2 倍；后续电池依次解锁 3、4、5 倍。档位位置固定为 0.5 倍 (90,87)、2 倍 (116,87)、3 倍 (142,87)、4 倍 (163,87)、5 倍 (184,87)。安装电池后不提供 1 倍档位。

滑块变更和电池变更会在服务端原子切换倍率。运行中的批次按照旧周期与新周期的比例换算已完成进度，并保留活动投入、预备投入、工具以及已经取得的流式输出权利；应力合同、剩余时间、输入需求节奏和输出结算节奏在同一 tick 使用新倍率。非黑盒运行与非蓝图模式保留电池和已选档位，但实际生效倍率为 1 倍且滑块不可操作。

超频保持整批物品、流体和工具耐久向量不变，并统一改变机械阶段时长；不能对每项数量分别取整。仍在真实空间执行的自然等待不被机械超频缩短；经过来源证明并冻结为黑盒合同的再生路线已经不再执行真实随机刻，因此其完整虚拟周期按超频倍率缩放。模拟模式只按倍率缩放生产负载，冻结在工厂内的发电能力保持学习值，并由两者重新计算净值和外部应力缺口；外部网络未补足缺口时从换算后的当前进度暂停。流式产物保留累计已取得数量，新时钟只会继续生成同一批次尚未取得的余量，因此切档不会补发或回收物品。护目镜显示当前生效倍率的计划效率，GUI 继续显示实时传输效率。

蓝图的最终机械效率定义为“来源生产效率 × 实际生效超频倍率”。当前蓝图来源效率仍为 100%，本决策只为未来来源效率采集保留乘法语义，不扩大本次功能范围。

客户端只负责拖动和吸附滑块；服务端根据菜单上下文校验模式、电池槽连续性和目标档位。客户端不能直接提交倍率或修改电池库存。菜单同步已选倍率、生效倍率和电池槽状态，以便在服务端拒绝或批次延迟生效时恢复权威显示。

GUI 主体沿用现有上半部分，玩家背包背景从纹理 (85,103) 开始。前三行背包槽首格位于 (91,137)，每格 16×16、间隔 2；快捷栏首格位于 (91,195)，同样为 16×16、间隔 2。四个烈焰电池槽位于 (90,69)、(130,69)、(151,69)、(172,69)。
