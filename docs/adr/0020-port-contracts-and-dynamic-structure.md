# 按逻辑端口记录路线并显式声明动态结构

激活后，若某种投入在当前可运行计划中只能归属一条路线，运行时允许从任意 INPUT 面接收并分派；具有多个可能路线、耦合条件或端口特定约束的投入仍必须从学习到的逻辑端口进入。该便利规则不改变计划保存的端口归因证据。

已经提交的产物形成共享输出托管，可从任意 OUTPUT 面提取；各路线仍分别保存批次与待交付数量，未交付产物不会被复制，也不会允许该路线无限积累后续批次。

路线投入和产出按逻辑端口 ID、传输方向与完整资源身份保存，同一 ID 的多个外壳面共享同一端口合同。结构验证使用修订号和紧凑签名，来源适配器声明刷石单元、树木等允许变化的动态区域及不变量；玩家或未知系统修改结构会改变修订号，学习只在开始和最终验证时计算完整签名，不再每 tick 扫描整个房间。
