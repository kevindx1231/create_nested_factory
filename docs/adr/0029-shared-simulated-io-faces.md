# 黑盒与蓝图使用工厂级共享输入输出面

黑盒和蓝图模式中的外壳面只声明 INPUT、OUTPUT 或 NONE 访问权限，不再参与配方指纹、路线归属或资源所有权。所有 INPUT 面共享同一个运行时需求视图，插入的物品和流体由路线调度器直接提交到缺少该资源的生产事务；所有 OUTPUT 面共享同一个工厂输出托管视图。修改外壳面不会停止黑盒、取消蓝图、清空运行时或复制资源。

模拟输入不经过端口 `inputItems`、`sealedInputItems` 或输入流体缓存。学习成功后，物理传输代次中尚未提交的资源按已确认的硬切规则销毁；旧存档只在加载黑盒或蓝图模式时清除旧模拟端口缓存，常加载工厂的物理传输缓存不受影响。普通物品、完整包裹和流体通过同一调度器按稳定路线顺序提交。

模拟输出统一写入一个稳定的工厂托管通道，外部从任意 OUTPUT 面读取聚合账本。没有输出面时产物仍可进入有限托管，达到容量后由运行事务等待输出；切换输出面只刷新能力。退出黑盒、取消蓝图或替换模拟合同会销毁未提取的模拟托管资源，蓝图只复制生产合同和建议面布局，不复制事务或资源。

常加载、准备和学习模式继续使用逻辑端口 ID 连接真实空间端口。ADR-0020 中模拟路线绑定特定逻辑端口的决定由本 ADR 取代；ADR-0014 中关于学习代次封口和真实空间传输托管的决定继续有效，但“残留输入成为黑盒预付输入”的部分不再适用于模拟模式。
