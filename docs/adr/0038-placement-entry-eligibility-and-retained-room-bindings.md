# 按本次放置分配入口资格，独立保留空间绑定

同一父空间只允许一个工厂使用内部空间，但允许继续放置受限蓝图工厂；入口工厂拆除后立即释放资格，旧方块不自动升级，新放方块才可创建空间。带绑定的旧工厂在入口被占用时仍允许放置，只能运行应用蓝图并冻结其原空间，拆除后继续保留原绑定；入口空缺时重新放置则恢复原空间，避免将临时入口限制变成永久数据丢失。

此决策替代 ADR-0011 中普通搬运不检查内部子工厂的规则，以及 ADR-0036 中终端占用唯一子节点的规则。普通挖掘、潜行扳手拆卸与显式销毁共用内部子工厂、玩家和变更锁保护；无空间工厂仍参与父级逻辑冻结，但不分配房间且拆除后结算为普通方块。入口限制随方块保存，物品绑定标记只在重新放置时消费；旧版无空间无效方块只迁移为蓝图工厂，不利用入口空缺生成空间。
