# 分阶段学习并原子发布树场路线

树场以五次完整的树苗、生长、收割和补种循环形成统计证据，并要求隔离学习阶段的输出端口实际输出过树木产物。循环数按树场累计，来源发现结束后新增位置不降低已完成样本数；第五次循环后保留输出收尾窗口。树场证据存在时，空气、原版树苗、原木和树叶之间的变化统一视为树木动态状态，不再逐格推断树冠范围。机器、储存方块和其他非树木方块仍按学习开始时的逐格快照严格校验，真实玩家编辑也立即使学习失效。校验失败日志同时给出首批差异坐标和方块身份。

混合工厂先用两个独立窗口验证物料加工路线，再封存物料输入并等待旧加工稳定，随后单独学习树场。两部分在学习期间都不执行虚拟生产；树场完成后以一个事务发布具有独立周期和应力合同的两条路线并冻结真实空间。这一原子切换避免真实房间和黑盒同时产出，也避免把加工产生的同身份物品归为免费树场产物。

计划格式硬切换为 7。旧计划不迁移，因为旧格式缺少分阶段路线或内部供能合同，不能安全恢复新版黑盒生产权。
