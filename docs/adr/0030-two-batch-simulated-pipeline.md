# 模拟生产使用双批次流水线

黑盒和蓝图的每条路线拥有一个活动批次和一个预备批次。任意共享 INPUT 面都可以在活动批次运行或交付产物时继续填充预备批次；两个批次的资源上限都来自完整配方向量，不设置每 tick、每个面或每个端口的传输配额。活动批次完成并将产物交给工厂输出托管后，预备批次原子提升为活动批次，下一 tick 直接累计生产时间。

两批均满时拒绝多余输入并由玩家外部库存承担缓存。模拟输出托管容量按每条路线两个输出交接单位求和；普通路线的交接单位是一批完整产物，按秒流式结算的再生路线使用一次流式结算可能产生的最大数量。输出能力可以在同一 tick 响应任意次数的提取，托管容量只提供背压，不构成速率限制。

活动输入、预备输入、活动进度、输出权利和工具分别持久化。资源只能沿外部、预备、活动、输出托管、外部的顺序移动；状态提升不复制资源，只有完成活动批次才销毁投入并生成输出。混合工厂按路线分别维护双批次所有权，调度器以稳定路线顺序分配共享输入。

超频变化会原子重定时所有路线：运行路线按完成比例换算进度，未运行路线直接重绑定新合同，活动与预备资源所有权保持不变。流式路线保留已取得的累计输出权利，新时钟最多等待下一次结算追平，不能重复生成同一批产物。该决定取代批次边界等待、降级重启，以及原设计中一次只能拥有一个输入批次、完成后必须回到空闲状态和模拟输出固定 64 物品信用的部分。
