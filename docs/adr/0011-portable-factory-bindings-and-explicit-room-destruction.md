# 使用可搬运绑定和显式空间销毁

每个工厂方块代表一个永久空间 ID。玩家普通破坏工厂方块时，Pocket 空间和工厂的可持久化状态保持不变；掉落的绑定工厂物品携带完整方块实体数据，并在重新放置后恢复同一个空间。绑定物品固定为单个堆叠，重复绑定不得覆盖已有入口。

根工厂只能在 Pocket 维度之外重新放置。嵌套工厂只能在原父工厂空间的合法位置重新放置，不能通过搬运改变根/嵌套层级或更换父工厂。放置校验失败时拒绝放置，绑定物品保留。

普通破坏不再因子工厂、玩家或房间变更锁而取消，也不再创建空间销毁任务。工厂方块移除只释放运行时注册；其 Pocket 房间继续保留，直到绑定工厂被重新放置。

空间销毁只能从工厂 GUI 的销毁按钮发起。服务端通过菜单上下文验证请求，拒绝存在玩家或任意子工厂的房间，并将销毁作为持久化房间任务执行。请求成功后立即移除旧方块并掉落一个全新的未绑定工厂方块；房间内容按任务预算异步清空，根空间分配在任务完成时释放。

本决策不提供更新前存档或旧掉落物的兼容迁移，也不扩展到 Create 机械结构移动。
