# ADR 0032：统一三观察区间黑盒学习

> 已被 [ADR 0033](./0033-event-group-learning-and-net-room-accounting.md) 取代；本文仅保留为历史记录。

## 状态

已接受。

## 决策

所有普通、再生和混合工厂共用一次连续学习会话。会话以三个等长观察区间建立、确认并原子发布最多两条路线的 v8 计划。再生机器通过版本化来源适配器提供事件和额度，主学习器不识别具体来源种类。

旧的第二轮验证、树场隔离阶段和来源专用超时被删除。学习失败保留真实世界变化并回到常加载模式，不恢复学习开始时删除的旧计划。旧格式计划和蓝图不迁移。

## 理由

连续窗口减少重复运行和房间扫描，资源并集与平均速率能容纳慢速或随机产物。事件证据、边界账本、来源额度和原子发布共同提供适度防刷能力，并让普通与无输入生产使用同一条编译路径。

## 后果

学习结果反映测试期间的真实供料、应力和堵塞情况。资源种类及效率无需跨窗口稳定，因此玩家应在目标运行条件下开始学习。无法定量归因的混合产物会安全失败。
