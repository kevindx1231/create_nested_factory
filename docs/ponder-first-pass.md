# 嵌套工厂 Ponder 初版

入口：在物品栏中将鼠标移到“嵌套工厂”物品上，按住 Ponder 提示的按键（默认 W）。

## 场景顺序

1. 一个方块，一座工厂：控制界面、进入空间、边界墙返回。
2. 让物品穿过工厂边界：外壳输入输出、内部端口 ID、物品传输方向。
3. 驱动内部产线：外部传动轴、嵌套应力端口、铁锭辊压为铁板。
4. 把真实产线转为黑盒：准备、三个观察区间、冻结、黑盒生产条件。
5. 用蓝图复用生产能力：空白蓝图复制、潜行右键应用、资源不随蓝图复制。
6. 工厂里面，还能放工厂：父子空间、直接子工厂限制、祖先冻结。
7. 搬运与保存工厂：绑定物品、原空间恢复、父级限制、永久清除区别。

已移除原方案的“黑盒的运行与维护”独立场景。

## 初版表现范围

- 共享一个 13×8×13 的教学剖面：左侧外部世界，右侧独立内部空间；黑色地面分隔两者。
- 内部房间和嵌套缩略房间均非实际尺寸，字幕说明真实嵌套房间为 16×16×16。
- 物流用移动物品和有向彩色连线表达；剖面不是可直接复制的自动化施工蓝图。
- 控制界面操作目前使用右键提示和文字说明，没有打开真实菜单或绘制完整 GUI 面板。
- 机械辊压机使用 Create 的辊压动画，黑盒通过停转与蓝色轮廓表达冻结。
- 学习进度通过三块依次出现的绿色标记表达，时间压缩，不代表固定学习时长。
- 全部内容为客户端 Ponder 演示，不创建真实 Pocket 房间，不发模式切换、蓝图或清除请求。
- 中英文均提供 7 个标题和 42 段字幕。

## 游戏内检查

- [ ] 嵌套工厂出现 Ponder 提示；共 7 场且顺序正确。
- [ ] 逐场完整播放，检查模型、字幕指向、遮挡与停留时间。
- [ ] 中文/英文切换后没有翻译键裸露或字幕错位。
- [ ] 机械辊压机的轴朝向正确、压头动作和铁锭/铁板更换可见。
- [ ] 三段学习标记依次出现，激活后内部停转而外部物品继续移动。
- [ ] 蓝图应用目标、子工厂及搬运后工厂出现的位置可辨认。
- [ ] 重播、上一步/下一步、关键帧跳转后无残留物品或重复标记。
- [ ] 关闭思索后真实工厂的房间、库存及模式未受影响。

## 资源维护

脚本位于 `src/main/java/com/createnestedfactory/create_nested_factory/client/ponder/`。
字幕位于现有 `en_us.json`、`zh_cn.json` 的 `create_nested_factory.ponder.*` 条目。
Ponder 字幕索引从 `text_1` 开始；调整台词顺序时需同步两种语言。

结构资源为 `assets/create_nested_factory/ponder/nested_factory/workshop.nbt`。
修改 `scripts/generate_ponder_workshop.py` 后运行 `python scripts/generate_ponder_workshop.py` 可重建；仅需 Python 标准库。

不打包 JAR 的编译与资源检查：`gradlew.bat compileJava processResources`。
游戏内视觉效果仍需实测确认。
